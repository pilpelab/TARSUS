**Date:** 2026-07-23

## 🔍 The Root Cause (FOUND!)

**THE PROBLEM:** The `SpectralSim` and `RTScore` columns existed in FragPipe's output (`psm.tsv`) but were **being discarded** during Step 7's join operation.

### Data Source

- **Where the columns come from:** FragPipe's first-pass search output (`psm.tsv`)
- **Evidence:** Both reference and our own FragPipe output contain these columns at positions 18-19
- **What was wrong:** Step 7's `first_sub` selection explicitly listed only specific columns to extract, **and SpectralSim/RTScore were NOT in that list**

### The Bug Location

**File:** `src/tarsus/steps/step07_analyze_outputs.py`  
**Lines:** ~272-280

```python
# BEFORE (BUGGY):
first_sub = first_psms.select([
    "Spectrum", "base", "Prev AA", "Next AA", "Protein",
    "first_intensity", "Retention", "Charge", "Protein Start",
    "Protein End", "Mapped Proteins", "Hyperscore",
    "Extended Peptide", "Number of Missed Cleavages", "Is Unique",
    # ❌ SpectralSim and RTScore missing from this list!
])
```

cols = list(joined.columns)

## 🎯 What These Columns Are

From FragPipe/Philosopher documentation:

- **`SpectralSim`**: Spectral similarity score (0-1 scale)
  - Measures how well the observed spectrum matches the theoretical spectrum for the assigned peptide
  - Higher = better match
  - Generated by Philosopher during peptide spectrum matching

- **`RTScore`**: Retention time prediction score
  - Predicts how well the actual retention time matches predicted RT
  - Generated by MSBooster (machine learning RT prediction model in FragPipe)
  - Lower values = better prediction accuracy

## ✨ Key Insight

The columns were **never missing** from the data - they were **deliberately excluded** during column selection in Step 7. This is a common pattern in data pipelines where developers explicitly select "needed" columns to reduce memory usage or improve performance, but accidentally create blind spots when upstream tools add new useful fields.

The fix is minimal, non-breaking, and restores the correct schema from FragPipe without any changes to the core algorithm.
