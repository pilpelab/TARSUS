## 🎯 What Was Wrong

The output files were missing 2 columns:
- Column 18: `SpectralSim` (spectral similarity score)
- Column 19: `RTScore` (retention time prediction score)

**Impact:** 67 columns instead of expected 69

---

## 🔍 Root Cause (Discovered!)

**The columns existed in the source data but were being explicitly excluded during Step 7.**

### Evidence

1. FragPipe's `psm.tsv` contains both columns at positions 18-19 ✅
2. Our Step 7 code reads this file correctly ✅
3. BUT: The code explicitly selected only a specific subset of columns ❌
4. SpectralSim and RTScore were NOT in that subset ❌

### The Bug

File: `src/tarsus/steps/step07_analyze_outputs.py` line ~277

```python
# BEFORE (BUG):
first_sub = first_psms.select([
    "Spectrum", "base", "Prev AA", "Next AA", "Protein",
    "first_intensity", "Retention", "Charge", "Protein Start",
    "Protein End", "Mapped Proteins", "Hyperscore",
    "Extended Peptide", "Number of Missed Cleavages", "Is Unique",
    # ❌ SpectralSim and RTScore missing!
```

### Change 2: Reorder Columns to Match Schema

After the join, columns need to be repositioned (they were appended at the end):

```python
# Reorder columns to match reference schema
cols = list(joined.columns)
if "Delta Mass" in cols and "SpectralSim" in cols and "RTScore" in cols:
    cols = [c for c in cols if c not in ["SpectralSim", "RTScore"]]
    delta_idx = cols.index("Delta Mass")
    cols = cols[:delta_idx+1] + ["SpectralSim", "RTScore"] + cols[delta_idx+1:]
    joined = joined.select(cols)
```

## 📖 What These Columns Are

**`SpectralSim`** (Spectral Similarity Score)
- Range: 0-1
- Generated by: Philosopher (peptide spectrum matching)
- Meaning: How well the observed spectrum matches the theoretical spectrum
- Higher is better

**`RTScore`** (Retention Time Prediction Score)
- Generated by: MSBooster (machine learning RT predictor)
- Meaning: How well the actual RT matches the predicted RT
- Lower is better
