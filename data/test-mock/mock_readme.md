# Mock Test Data

Small mzML file (2000 MS2 spectra, 17.9 MB) extracted from real Orbitrap Astral DDA data.
Used for fast pipeline validation without processing 6--8 GB files.

Generated by: `scripts/make_mock_mzml.py`
Source: `HouYM-25-G140-AstralDDA-AlaGGC-HS-1.mzML` (E. coli K12, HS fraction)

## Usage

Run the full pipeline against mock data in ~2 minutes (local mode):

    uv run tarsus run --fasta data/protein.fasta \
        -i data/test-mock/dev.mzML \
        -o output/mock-run/ --local

Run specific validation tests via LSF:

    uv run pytest tests/validation/test_step02_index.py -v -m lsf
    uv run pytest tests/validation/test_step03a_first_pass.py -v -m lsf
